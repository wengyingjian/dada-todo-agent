# Dada 任务中心 (Dada Todo Agent)

> 一款基于 Obsidian 笔记的任务中心插件，全部基于纯 Markdown 复选框——管理自己的待办，还能**把任务委派给 [T3 Code](https://github.com/t3code-ai/t3-code) 的 AI agent，并让会话进度反向同步回你的笔记**。无账号、无云端、无锁定。

[English](./README.md) · 简体中文

---

**Dada 任务中心** 基于 [Dada Todo List](https://github.com/wengyingjian/dada-todo-agent) fork 并大幅演进：保留了原任务管理器的全部能力（七种视图、内联语法、拖拽改期……），并深度集成 **T3 Code**——把任意清单项一键委派给 AI agent，会话状态实时同步回任务行，侧边栏可直接查看和对话运行中的会话，历史会话也能导入进你的笔记。

### 🎯 这个插件适合你吗？

- 🤖 **你用 Obsidian 管任务、用 T3 Code 跑 agent** —— 这个插件就是两者之间的桥：清单文件是你的指挥室，agent 会话变成带实时状态的任务行，一切仍是纯 Markdown。
- 📝 **你只想要一个好用的任务管理器** —— T3 集成完全可选，不配置就是一个自包含的、纯 Markdown 驱动的任务与清单管理器。

### 💡 快速上手

1. 建议开启核心插件「**日记**」（设置 → 核心插件）——有日期的任务就存在你的每日笔记里；
2. 点击左侧栏的 ✅ 图标（或命令面板「打开 Dada Todo List」）打开面板；
3. 在任意一篇每日笔记里写下一行 `- [ ] 买牛奶 #生活`，面板里立刻就能看到。

### ✨ 功能特性——任务管理

#### 🗓 七种视图，随意切换

| 视图 | 适合场景 |
|---|---|
| **日视图** | 聚焦一天：时间轴 + 凌晨列表 + 全天任务 |
| **周视图** | 一周七天并排时间轴，定时任务按泳道排布、互不遮挡 |
| **月视图** | 整月日历格：农历、节气、节日、法定节假日（休/班）一目了然 |
| **日程** | 按日期纵向滚动的议程：已延期 → 未来 7 天 → 更远 |
| **四象限** | 按优先级 2×2 分区，象限内按日期分组，已完成的单独收进「已完成」分组 |
| **清单** | 按 `###` 标题分组管理清单文件，支持列表 / 分栏两种布局；标题行右侧 + 可新建清单，清单右键可归档 |
| **列表** | 全部任务池：按标签、日期、清单、状态（已完成 / 已取消）多维筛选 |

#### ✏️ 顺手的任务编辑

- **标题内联语法**：直接写 `#标签` 和 `[文字](链接)`，渲染为可点击的标签胶囊与超链接
- **时间灵活**：单时间、时间段、全天、**跨日期**四种形态一键切换
- **子任务**：无限层级缩进即子任务，弹窗内直接增删改
- **任务优先级**：高 🔺 / 中 🔼 / 低 🔽 三档，读写兼容 obsidian-tasks 插件
- **标签颜色**：在设置中为任意标签指定颜色，任务块、日程卡片与标签胶囊随之着色
- **清单迁移**：新建任务可选清单，编辑任务可跨清单移动（日期语义自动随迁）

#### 🖱 效率操作

- **拖拽改期**：周 / 月视图之间拖拽任务即可改期；时间轴上还能拖动手柄精细调整开始 / 结束时间
- **Option/Alt + 拖拽 = 复制任务**：按住 Option（Mac）/ Alt 或 Ctrl（Windows·Linux）拖动，落点新建副本、原任务保留
- **过期待办顺延**：一键把所有已过期任务顺延到今天
- **视图菜单自定义**：勾选控制各视图显示、拖拽调整顺序
- **到点提醒**：系统通知或应用内提示 + 「哒—哒」提示音。⚠️ 仅桌面端生效
- **自动归档**：清单中已完成的任务块在静置一段时间后自动搬入归档清单（有 24h 保护，启动空闲时执行）

#### 🔒 数据与隐私

- **纯 Markdown**：任务就是笔记里的复选框，插件删除后数据原样保留
- **全本地**：不依赖任何外部服务，天然适配各种同步方案
- **只读接入 T3**：T3 Code 的会话数据存在 T3 自己的存储里，插件只读取它的数据库、往你的笔记里写任务，从不改动 T3 的数据

### 🤖 功能特性——T3 Code agent 中心

以下能力均为可选，配置好 T3 Code 后自动激活。

- **一键委派**：任务编辑弹窗、清单视图、编辑器纸飞机按钮均可把任务委派给 T3 Code agent。委派后任务下方出现一条子行，先显示委派内容摘要，随后实时更新状态：进行中 → 等你回答 → 已完成 / 失败
- **项目 = 清单文件**：一个项目就是一份 frontmatter 带 `cwd` 的清单文件。在该目录下产生的 T3 会话自动同步进项目清单，按状态归入 `### 进行中` / `### 待处理` / `### 已完成` 分组
- **反向同步**：插件监听 T3 Code 的 SQLite 数据库，把会话状态同步回任务行——复选框状态原地更新，完成的会话原地替换为一行总结，未绑定的新会话按 cwd 归属写入对应项目文件或当天日记。静默期 + prompt 计数双门槛控制再总结频率
- **LLM 会话总结**：配置 OpenAI 兼容接口后，完成的委派会被改写成「短标题 + 编号要点」；未配置则回退为截断的对话摘要
- **会话侧边栏**：独立右栏视图（搜索框、今日协作时长统计、按项目的活动时间轴），列出全部 T3 会话：待处理 / 进行中 / 已完成，点击项目时间轴可筛选会话卡片。监听 SQLite WAL 变更近实时刷新
- **对话弹窗**：从侧栏或任务行打开任意会话：读消息（自动定位最新）、回车发送回复、直接回答 agent 的提问（选项点选 + 自定义输入）。通过内置 OAuth 授权流程支持全权限会话的代答
- **清单管理增强**：UI 直接新建清单（名称 + 可选 cwd，支持系统文件夹选择）、右键归档清单、清单间迁移任务

#### ⚡ 会话标记语法

委派或反向同步时，插件会在任务行尾维护 `⚡ t3:<会话id>` 标记，这是行与会话的绑定凭据，**请勿手动编辑**：

```markdown
### 已完成
- [x] 09:10-09:13 调研顶部统计 UI 📅 2026-11-20  ⚡ t3:9220a55#3
  1. 要点一：……
  2. 要点二：……
```

### 🚀 安装

**手动安装**：下载 `main.js`、`styles.css`、`manifest.json` 三个文件，放入
`你的库/.obsidian/plugins/dada-todo-agent/` 目录，然后在设置中启用第三方插件并开启本插件。

**BRAT**：安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 后添加本仓库地址即可自动更新。

### 📁 数据存储

| 数据 | 位置 |
|---|---|
| 有日期的任务 | **日记文件夹**设置指定的文件夹，任务即这些笔记正文中的复选框 |
| 无日期的任务（收件箱） | 默认库根目录 `DadaTodoList.md`，可在设置中修改；不存在时启动自动创建 |
| 清单与项目 | frontmatter `tags` 含 `todoList`（可改）的笔记；项目额外带 `cwd` 字段 |
| 插件设置 | 插件目录下的 `data.json`（含可选的 T3 OAuth token） |

一切皆纯 Markdown。卸载插件不影响任何笔记内容。T3 Code 的会话数据在其自有存储中，插件只读不写。

### 📝 清单文件的写法

任意一篇笔记，只要 frontmatter `tags` 含有清单识别标记（默认 `todoList`）就会成为一份清单。文件里用 **`###` 三级标题作为分组依据**：

```markdown
---
tags:
  - todoList
---

### 工作
- [ ] 完成季度汇报 #work
    - [ ] 收集数据
- [x] 回复客户邮件

### 生活
- [ ] 预约牙医
```

规则与技巧：

- **`###` 标题 = 分组名**，可增删改；标题前的任务归入「未分组」
- **缩进的复选框 = 子任务**，层级不限
- 清单视图支持**列表 / 分栏**两种布局；**拖拽任务到其他分组**即可移动归属
- 每个分组标题旁有 **+ 按钮**；侧栏实时显示各清单的完成进度
- 「清单」列表标题行右侧 **+ 按钮** 新建清单：可填名称与可选 **cwd**（支持系统文件夹选择），默认存到「清单」文件夹（设置项可改）
- 清单列表上**右键 → 归档清单**：frontmatter `tags` 加 `archived` 即不再显示，去掉标签可恢复

### ⚙️ 设置

| 设置项 | 说明 |
|---|---|
| **打开位置** | 左侧栏 / 主工作区标签页 / 右侧栏 |
| **主题配色** | 任务块的配色方案（7 种）；按任务标题取色 |
| **显示农历与节假日** | 日 / 周 / 月视图中的农历、节气、节日及休 / 班标记 |
| **日记文件夹 / 日记载入范围** | 有日期任务的存放位置；大库可限制加载天数提升性能 |
| **收件箱文件** | 无日期任务的存放文件，更换路径时支持整体迁移 |
| **清单文件夹 / 清单文件 tag 标记** | 新建清单的落点；哪些笔记算清单（含 `archived` 即已归档） |
| **每周开始日 / 时间轴显示范围 / 视图菜单** | 各视图显示偏好 |
| **完成任务时添加完成日期标记** | 勾选时行尾追加 ✅ 日期 |
| **任务到点提醒 / 全天任务提醒** | 通知方式与全天任务统一提醒时刻 |
| **T3 可执行文件路径** | `t3` CLI 位置，留空自动探测 |
| **T3 provider / model** | 委派会话的模型覆盖 |
| **项目默认工作目录** | 委派弹窗 cwd 预填 |
| **反向同步** | 把 T3 会话状态同步回笔记（默认开启） |
| **反向同步最小年龄（分钟）** | 会话至少存在这么久才会被写入文件（默认 3），避免抖动 |
| **总结 LLM（接口 / 模型 / 密钥）** | OpenAI 兼容接口；三项任一为空则回退为截断摘要 |
| **总结 Prompt 模板** | 自定义总结提示词（支持 `{{delegation}}` / `{{transcript}}` 占位符） |
| **总结静默分钟数** | 完成的会话静默这么久后才允许再总结（默认 30） |

### 🌐 语言

界面跟随 Obsidian 的语言设置（简体中文 / 繁體中文 / English）。切换后重启 Obsidian 生效。

## 🛠 开发

```bash
npm install
npm run build     # 生产构建（产物：dada-todo-agent/main.js、styles.css、manifest.json）
npm run dev       # 开发模式：监听 src/ 改动自动重建
node --test src/project/reverse-sync.test.mjs   # 运行单个单测文件（node:test）
node scripts/install.mjs                        # 构建 + 部署到开发库的插件目录
```

本地调试：把测试库的插件目录软链到产物目录即可（目录名须与插件 id `dada-todo-agent` 一致）：

```bash
ln -s "$(pwd)/dada-todo-agent" "你的库/.obsidian/plugins/dada-todo-agent"
```

> 改动代码后必须执行 `node scripts/install.mjs`（只跑 `npm run build` 不会更新 Obsidian 里的拷贝），然后在 Obsidian 中重载插件才能生效。
